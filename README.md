# Ryūmon Pathfinder

A free field guide for students choosing a path into computing. It covers 20 paths, including computer science, coding, data, AI, prompting, computer engineering, security and design. Each path has a four-stage roadmap where every step links to a course, book or tool.

## Features

- **20 career paths**, each with skills, roles, a first project and a ticked-off roadmap
- **A 7-question quiz** that ranks the paths as you answer
- **"My pond"** to save the paths you like
- **Works offline after loading.** It's one self-contained HTML file with no build step, no tracking and no outside requests.

## Privacy

There are no accounts, cookies or analytics. Saved paths, ticked steps and quiz answers stay in the visitor's own browser (`localStorage`), and the page has a button to clear them.

## Running it

Open `index.html` in a browser, or serve the folder with GitHub Pages.
